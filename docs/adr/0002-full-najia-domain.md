# ADR-0002 · 补全真六爻装卦体系

- 状态：已接受（2026-11-09）
- 影响：ROADMAP M1 / M3；`src/lib/`、`src/data/hexagrams.json`、结果卡 UI

## 背景

现实现为「三枚铜钱起卦 → 查 64 卦表」，输出卦名、卦辞、象辞与一段白话解读。六爻占法的核心步骤——**装卦**——完全缺失：

- 纳甲：各爻配天干地支
- 世应：定世爻与应爻
- 六亲：按卦宫五行配父母/兄弟/子孙/妻财/官鬼
- 六兽（六神）：按日干起青龙…玄武
- 旬空：按日柱定空亡
- 月建日辰：月令与日辰对爻的生克扶抑
- 用神/原神/忌神/仇神与旺衰生克的简断

名称叫「六爻」，实际只是「金钱卦查表」。对懂行的用户是玩具，对不懂的用户解释力也不足。

## 决策

1. 在 `src/lib/domain/` 实现完整装卦链路，**纯函数、零 DOM 依赖**，可独立测试；
2. 装卦全表（64 卦 × 各爻干支六亲世应）由脚本从纳甲歌与卦宫规则**生成**而非手抄，配套校验脚本防手误；
3. 引入 Vitest，用教材经典卦例做黄金用例（目标 ≥ 20）；
4. 结果 UI 分层呈现：卦象图 → 装卦表 → 断语 → 卦爻辞 → 白话。

## 流派口径

装卦细节存在流派差异。本项目的取舍：

- 世应起法：京房八宫 standard（一世至归魂）
- 六兽起法：按日干起，甲乙起青龙……
- 旬空：以起卦日柱查旬空
- 旺衰：只做月建/日辰生克冲合的简断，不做复杂的卦气旺衰

口径来源与理由写在对应模块注释中；如与某流派不合，欢迎开 issue 讨论（带出处）。

## 后果

- 正面：「六爻」名副其实；内容成为壁垒；解读可信度与可解释性提升。
- 负面/风险：解读文案量数倍增长，需人工校对；流派差异会被较真的用户挑战——把口径透明化是应对方式。
